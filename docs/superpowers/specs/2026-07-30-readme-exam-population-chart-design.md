# README 會考人數推估圖表設計

日期：2026-07-30

## 目標

將最新的 `exam_population_116_130.csv` 轉成可重複產生的 SVG 折線圖，
並嵌入 GitHub README。圖表必須同時呈現新竹縣、新竹市、苗栗縣與
三區合計，且明確區分民國 130 年的暫估值。

## 輸入與輸出

- 預設輸入：`data/population/exports/` 中目錄名稱最新、且包含
  `exam_population_116_130.csv` 的輸出。
- 指定輸入：CLI 可接受明確 CSV 路徑，方便測試及重現舊版本。
- 預設輸出：`docs/images/exam-population-116-130.svg`。
- 指定輸出：CLI 可接受明確 SVG 路徑。
- CSV 以 `utf-8-sig` 讀取，保留目前 UTF-8 BOM 相容性。

## 元件與資料流

新增 `scripts/render_exam_population_chart.py`，將責任分成三個小單元：

1. 找出最新 export，或接受使用者指定的 CSV。
2. 驗證必要欄位並載入 116–130 年的四個人數序列。
3. 將資料轉成固定尺寸、可縮放且可存取的 SVG，再以原子方式寫入輸出。

程式只使用 Python 標準函式庫，不新增繪圖套件。產圖不會改動 CSV、
SQLite 或 raw 原始資料，也不自動執行人口資料下載。

## 圖表呈現

- 使用單一線性座標折線圖，橫軸為民國會考年度，縱軸為預估人數。
- 新竹縣、新竹市及苗栗縣使用三條清楚可區分的細線；三區合計使用較粗
  的線，並以線條樣式、標籤與顏色共同傳達系列身分。
- 每個年度保留資料點及千分位人數標示；標示依系列使用固定錯位，降低
  重疊。
- 民國 130 年資料點使用空心標記，並加上「暫估：各地補 2 月」註記。
- SVG 包含標題、資料來源說明、非實際報考人數聲明、圖例、座標單位、
  `<title>` 與 `<desc>`。
- README 在專案說明與方法限制之後嵌入圖表，並連結原始 CSV。

## 失敗處理

下列情況必須以非零 exit code 與明確錯誤訊息失敗，且不得留下半成品
SVG：

- 找不到預設或指定的 CSV。
- 缺少年度、四個人數序列或資料完整性欄位。
- 年度重複、不連續、超出 116–130，或人數不是非負整數。
- 資料列數不是 15，或民國 130 年未標示為暫估。

## 驗證

- 單元測試驗證最新 export 選擇、BOM CSV 解析與資料驗證。
- 單元測試驗證 SVG 具有四個系列、15 個年度、暫估標記、可存取文字及
  來源資料中的代表值。
- 單元測試驗證缺欄位與錯誤數值時不產生 SVG。
- 執行現有完整測試、`compileall`、artifact validator 與
  `git diff --check`。
- 將最後 SVG 實際轉成預覽圖並檢查文字、線條、標示與 README 顯示尺寸。
