# Add ROC Exam Year 115 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the default household-registration cohort estimate, immutable CSV exports, README chart, and documentation from ROC exam years 116–130 to 115–130.

**Architecture:** Keep the estimator generic and change only public defaults plus range validation. Publish a new offline timestamp export without altering existing data, then make the chart renderer and README consume the new 16-year file.

**Tech Stack:** Python 3.11+ standard library, SQLite, CSV, SVG, `unittest`

## Global Constraints

- Use the existing single-age household-registration weighting method without a year-115 special case.
- Default range is exactly ROC 115–130; explicitly supplied ranges remain supported.
- Expected year-115 values are 新竹縣 5,951, 新竹市 4,666, 苗栗縣 4,287, and 三區合計 14,904.
- Year 115 must be `完整 cohort`; only year 130 is provisional.
- Do not alter any existing file under `data/population/`; add exactly one new timestamp export directory.
- Do not download population data or modify raw archives or SQLite.
- Replace the current README SVG with `docs/images/exam-population-115-130.svg`.
- Run every test, compilation, validation, rendering, hashing, and Git command under `caffeinate -i -m`.
- Commit and push each independently reviewable unit to `feature/add-exam-year-115`, then fast-forward and push `main`.
